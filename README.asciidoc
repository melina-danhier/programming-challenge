= Weather and country data challenge

This application evaluates two CSV data sets:

* It determines the day with the smallest difference between maximum and minimum temperature.
* It determines the EU country with the highest population density.

For the supplied data, the results are day `14` and `Malta`.

== Build and run

Java 11 or newer is required. The project can be built and tested with the included Maven wrapper:

[source,bash]
----
./mvnw verify
----

On Windows, use `mvnw.cmd verify` instead. Run the application with:

[source,bash]
----
./mvnw exec:java
----

The program prints both results to standard output.

== Design

The implementation separates the import pipeline from the two calculations:

`DataFileReader`::
Reads records from a data source. `CSVFileReader` is the CSV implementation used by this application.

`DataMapper`::
Maps a source record to a small domain object. Weather and country data use separate mappers.

`DataImportService`::
Composes a reader and mapper into a reusable import flow and loads classpath resources as UTF-8.

Domain objects::
`WeatherRecord` and `CountryRecord` contain only the values required by their calculation and expose the derived temperature spread or population density.

Services::
`WeatherService` and `CountryService` select the requested result without depending on CSV or resource handling.

Validators::
Dedicated validators enforce the invariants needed by each calculation before a domain object is created.

This division keeps file access, parsing, validation, and business rules independently testable. The generic reader and mapper interfaces also allow another input format, such as JSON or a web service, to be introduced without changing the calculation services.

== Implementation decisions

=== CSV parsing

Apache Commons CSV is used instead of manually splitting lines. It handles quoting and configurable delimiters and avoids coupling the implementation to incidental formatting details.

The weather file uses commas, while the country file uses semicolons. The delimiter is therefore a configuration of `CSVFileReader`, not duplicated parsing logic.

Required values are accessed by header name rather than column position. Reordering columns consequently does not affect the import. Only fields required for the calculations are mapped, so malformed values in unrelated columns do not invalidate otherwise usable input.

=== Numeric values

Weather temperatures are parsed as finite `double` values. Country population and area are integral values because people and square-kilometre figures in the source data are whole numbers.

The supplied country data contains both plain integers and a German-style grouped population value such as `4.036.355,00`. The country mapper accepts these two explicit whole-number representations. Other or ambiguous representations are rejected instead of being interpreted silently.

Population density uses floating-point division to avoid integer truncation.

=== Validation and errors

Invalid input fails fast with a descriptive exception:

* Missing resources produce a `DataFileNotFoundException`.
* CSV parsing and mapping failures produce a `DataImportException`.
* Invalid domain values are detected through `ValidationException` and enriched with CSV record context by the mapper.

The application rejects non-positive days, non-finite temperatures, a maximum temperature below the minimum, blank country names, negative populations, and non-positive areas. Empty input collections are rejected by the calculation services because no meaningful result exists.

=== Equal results

If several weather records have the same smallest spread, the first record is retained. The country calculation follows the same deterministic first-record behaviour for equal densities.

== Tests

The test suite contains focused unit tests for readers, mappers, validators, and calculation services. Integration tests load the supplied classpath resources and verify both the number of imported records and the final results. Error-path tests cover missing resources and headers, malformed numbers, invalid domain values, empty inputs, delimiter configuration, and quoted CSV values.
